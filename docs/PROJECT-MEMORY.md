### Утвержденная логика видеошапки

**Главная:**

- Вариант 1 (`var 01.mp4`).
- Попытка автоматического воспроизведения со звуком при первом открытии.
- Если браузер блокирует звук — видео работает без звука.
- Клик по баннеру запускает звук Варианта 1 на один проход.
- После прохода auto mute.
- Далее плавный loop.

**Разделы:**

- Вариант 4 (`в работу.mp4`).
- Клик по острову запускает видео со звуком на один проход.
- После прохода auto mute.
- Далее плавный loop.
